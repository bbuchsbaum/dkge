# Paint values defined on an identified reference support

Paint values defined on an identified reference support

## Usage

``` r
dkge_paint_reference_map(values, labels, out_file = NULL)
```

## Arguments

- values:

  Vector or matrix of values defined on the reference labels.

- labels:

  Labels describing the identified target support.

- out_file:

  Optional output path.

## Value

A `BrainVolume` or output path, depending on `out_file`.
