# Iterative functional-template validation

`known-warp-protocol.json`, `known-warp-metrics.csv`, and
`known-warp-result.rds` are generated by
`inst/validation/functional-alignment-template/run-template-benefit.R`.

The frozen v1 scenario uses balanced cyclically warped anatomical coordinates,
independent functional features, and held-out subject maps. It compares the
iterative template against a raw functional medoid, geometry-only Sinkhorn
transport, and ordinary coordinate-space kNN averaging. The pass gate requires
convergence, independent prediction, auditable amplitude, and a correlation
advantage over the two geometry-only arms. The raw-medoid comparison is always
reported but is deliberately not a pass gate: a favorable or unfavorable
efficacy result cannot change the template's approximate inferential label.
