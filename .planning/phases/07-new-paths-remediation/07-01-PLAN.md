# Phase 07 — New-paths remediation plan

Source: `data-raw/audit-2026-08-17-new-paths-review.md` (findings N1–N6,
significant items S1–S12, vignette items V1–V6 + non-blocking, hygiene H1–H4).
Rule for every task: **write the regression test first, watch it fail, fix,
watch it pass, then run the slice's test files.** Never weaken an existing
test; where an existing test locks in the wrong behaviour, replace its
assertion with the oracle named below. Numeric oracles are hand-computed or
independent (`svd`, `model.matrix`, dense refit), never a restatement of the
implementation.

Work is grouped into six work packages (WP-A … WP-F) by file ownership so
they can run in parallel worktrees without conflicts. Each WP ends with the
listed test files green and `devtools::document()` producing no diff beyond
the WP's own roxygen edits. The phase ends with the gate in §7.

Verification harness shared by all WPs (create once, `tests/testthat/helper-audit-0817.R`):

- `make_permuted_cell_fit(seed)` — 2×3 cell kernel via `design_kernel(basis="cell")`;
  subjects whose beta rownames / design colnames are a fixed *non-identity*
  permutation of `grid$cell_labels`; returns fit + the permutation.
- `make_partial_fit(seed, w_method, ...)` — S=6, q=4, subject 1 full coverage,
  subjects 2–6 `observed_rows = 1:3`; returns fit and the raw `B_list`.
- `null_aggregate_target(seed, n=16, q=4, p=25)` — pure-null aggregate target
  with a `grp` factor for `dkge_aggregate_permute`.
- `type1_rate(fun, n_rep, alpha=0.05)` — loops seeds, returns rejection rate;
  used only in `skip_on_cran()` calibration tests with fixed seeds.
